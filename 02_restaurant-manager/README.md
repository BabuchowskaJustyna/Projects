# Restaurant Manager

Restaurant management in Python (OOP, unit tests, logger, modular structure).

## Project Structure

- `models.py` – data classes: Table, Dish, MenuItem, statuses
- `manager.py` – order logic: Order, OrderManager
- `interfaces.py` – interfaces: WaiterInterface, KitchenInterface
- `main.py` – example usage
- `tests/` – unit tests (unittest)
- `menu.json` – sample menu

## How to Run

```bash
python main.py
```

## Unit Tests

```bash
python -m unittest discover tests
```

## Key Features
- Object-oriented approach (OOP)
- Modular code structure
- Logger instead of print statements
- Unit tests
- Type hints and docstrings
