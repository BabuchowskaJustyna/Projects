# NLP: AI vs Human Text Classification

This project applies Natural Language Processing (NLP) techniques to classify whether a given text was written by a human or generated by artificial intelligence. The workflow includes data preprocessing, lemmatization, feature extraction, and machine learning classification using Python.

---

## Problem Statement

**Objective:** Predict whether an input text is **human-written (0)** or **AI-generated (1)**.

**Dataset:** [AI vs Human Text Dataset on Kaggle](https://www.kaggle.com/datasets/shanegerami/ai-vs-human-text/data?select=AI_Human.csv)

- **Target variable:** `label`
  - `0` — Human-written text
  - `1` — AI-generated text

---

## Workflow Overview

1. **Data Loading:**
   - Load and shuffle the dataset from CSV.
2. **Text Preprocessing:**
   - Lowercasing, removing digits, punctuation, and HTML tags.
   - Tokenization and lemmatization using NLTK and spaCy stopwords.
3. **Feature Extraction:**
   - Convert text to numerical features using TF-IDF vectorization.
4. **Model Training:**
   - Train and evaluate two models:
     - Multinomial Naive Bayes
     - Random Forest (with hyperparameter tuning via GridSearchCV)
5. **Evaluation:**
   - Assess models using accuracy, precision, recall, F1-score, and confusion matrix.

---

## Tools & Technologies

- Python 3
- Pandas, NumPy
- NLTK (Lemmatization, POS tagging)
- spaCy (Stopwords)
- Scikit-learn:
  - TfidfVectorizer
  - Multinomial Naive Bayes
  - Random Forest, GridSearchCV
  - Confusion Matrix, Classification Report
- Matplotlib (visualization)

---

## Results

- **Multinomial Naive Bayes** achieved high accuracy, especially in identifying human-written texts.
- **Random Forest** (with hyperparameter tuning) struggled to balance precision and recall for both classes.
- Text preprocessing and TF-IDF vectorization were crucial for model performance.

## How to Run

1. Download the dataset from Kaggle and place `AI_Human.csv` in your working directory.
2. Install required packages:
   ```bash
   pip install pandas numpy scikit-learn nltk spacy matplotlib
   ```
3. Download NLTK resources (in your notebook or script):
   ```python
   import nltk
   nltk.download('wordnet')
   nltk.download('omw-1.4')
   nltk.download('averaged_perceptron_tagger')
   nltk.download('averaged_perceptron_tagger_eng')
   ```
4. Run the notebook `nlp_project_ai_human.ipynb` step by step.
